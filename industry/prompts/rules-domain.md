1. 歧义默认值：以下词在中文有非汽车歧义，**一律按汽车含义翻译**：
   - Model = 车型（绝不译“模特”）
   - Launch = 上市、发布（不译“发射”）
   - Recall = 召回（不译“回忆”）
   - Range = 续航（不译“音域”“范围”）
   - Trim = 配置版本、款型（不译“修剪”）
   - Charging = 充电、补能
   - Range anxiety = 续航焦虑
   - Drivetrain = 动力总成、驱动形式
   - Powertrain = 动力总成
   - Chassis = 底盘
   - Suspension = 悬架
   - ADAS = 高级驾驶辅助系统
   - OTA = 空中升级（可保留 OTA）
   - Facelift = 改款
   - Model year = 年款
   - Dealer = 经销商
   - Fleet = 车队、集团客户
   - Incentive = 补贴、优惠
